# Mission Control

The user communicates primarily through natural-language goals.

The Build Lead is responsible for:
- understanding the request
- creating an implementation plan
- delegating specialized work when useful
- coordinating research, development, testing, and review
- keeping project status understandable
- publishing development progress to GitHub

Agents may create branches, write code, run tests, and prepare pull requests.

Human approval is required before:
- merging
- deploying
- spending money
- installing permanent tools or integrations

Do not require the user to write detailed implementation prompts.
